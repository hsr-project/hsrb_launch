hsrb_launch
============

概要
-----------------------

HSRBのソフトウェアを一括して起動するlaunchを集めたリポジトリ。
各環境(実機、シミュレータ)用のlaunch及び、共通のlaunchを管理する。


パッケージ一覧
----------------------

* `hsrb_common_launch`

    共通のlaunchファイルを管理するパッケージ。

* `hsrb_gazebo_launch`

    Gazeboシミュレータ用の一括起動launchファイルを管理するパッケージ。

* `hsrb_robot_launch`

    実機用の一括起動launchファイルを管理するパッケージ。
